# Личная записка Олега и Машеньки

> Этот файл хранит рабочий смысл проекта. Он находится в репозитории, поэтому не является секретным хранилищем: ключи, пароли, токены и личные данные сюда не добавляем.

## Что мы строим

VideoT16 — локальная система компьютерного зрения для ноутбука, камеры и полётного контроллера. Она получает видеопоток с Logitech Brio, пропускает кадры через локальную YOLO-модель и накладывает на видео OSD с телеметрией INAV.

Главная идея — сначала спокойно отладить всё на ноутбуке, а потом перенести готовый облегчённый вариант на Orange Pi. Так мы не заставляем маленькую плату страдать в роли лабораторной мыши, а заранее проверяем архитектуру и поведение на нормальном компьютере.

## Что уже работает

- локальное распознавание на CPU без облачного ИИ;
- внешняя камера Logitech Brio;
- вывод видео на второй HDMI-монитор;
- подключение LongBow F405 Wing с INAV по `/dev/ttyACM0`;
- чтение телеметрии MSP только в режиме чтения;
- OSD с креном, тангажом, курсом, скоростью, `ALT`, `AGL`, `SAT` и `RSSI`;
- батарея: напряжение, ток, расход `mAh`, остаток и процент;
- рамки объектов с единой подписью `OBJECT` и уверенностью;
- звуковое оповещение после удержания обнаружения;
- режим проверки ограничений Orange Pi;
- подготовка моделей к будущему запуску на NPU Orange Pi 5.

## Основные файлы

- `src/local_object_detection.py` — точка входа и главный цикл видео;
- `src/inav_msp.py` — чтение телеметрии INAV по MSP;
- `config/osd_config.py` — внешний вид OSD;
- `run_military.sh` — запуск модели военной техники;
- `run_modeling.sh` — запуск режима моделирования с полётником;
- `scripts/orangepi4_mode.py` — проверка ограничений ресурсов;
- `models/` — локальные веса моделей;
- `docs/` — подробные инструкции и описание OSD.

## Запуск моделирования

Пример запуска с батареей 2200 мА·ч:

```bash
cd /home/work/VideoT16
source .venv/bin/activate

./run_military.sh \
  --confidence 0.50 \
  --inav-port /dev/ttyACM0 \
  --battery-capacity-mah 2200 \
  --resolution 1920x1080 \
  --window-x 1920 \
  --window-y 0 \
  --fullscreen \
  --alert-delay 3
```
