# Резервная копия разработки VideoT16

Этот каталог содержит способ быстро собрать переносимый архив именно нашей
разработки для Raspberry Pi.

## Что попадёт в архив

- исходный код `src/` и `config/`;
- `run_raspberry.sh`, systemd-шаблон и рабочие скрипты;
- тесты `tests/`;
- документация проекта;
- `requirements-raspberry.txt`;
- только утверждённая модель `models/fpv_drone_best.onnx`;
- исходники средств безопасности без production-секретов;
- контрольный список файлов и SHA-256 манифест.

## Что намеренно не попадёт

- Linux, системные пакеты и настройки самой Raspberry Pi;
- `.git/` и история репозитория;
- `.venv/`, `__pycache__/` и кэши;
- большой датасет `dataset/` и результаты `runs/`;
- `production_payload.v16e`, `production_activation.json`, `launcher.py`;
- `security/auto.py`, локальные фразы, ключи, пароли и сетевые секреты;
- личные изображения и временные файлы.

Это сделано специально: архив восстанавливает разработку, но не содержит
секретный production-пакет и не пытается сохранять операционную систему.

## Как собрать архив

Из корня проекта:

```bash
cd /home/work/VideoT16
bash BACKUP/make_backup.sh
```

Скрипт сначала показывает состав и размер, затем просит подтверждение
`СОХРАНИТЬ`. Архив создаётся в `BACKUP/` с датой и временем. Перед записью
проверяется, что в него не попали запрещённые пути.

## Как восстановить

На чистой Raspberry Pi:

1. установить Raspberry Pi OS и системные пакеты;
2. распаковать архив в `/home/oleg/VideoT16`;
3. установить зависимости из `requirements-raspberry.txt` в новый `.venv`;
4. отдельно передать свежий зашифрованный production-пакет;
5. установить systemd-службу и проверить `vtest`.

Архив не является образом SD-карты и не заменяет резервную копию Linux.
