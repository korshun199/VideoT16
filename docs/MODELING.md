# Ветка моделирования

## Зачем создана ветка

Ветка `modeling` предназначена для разработки и проверки системы на ноутбуке.
Здесь можно безопасно менять код, смотреть логи, подключать полётный контроллер
и проверять вывод на HDMI-монитор без ограничений автономного устройства.

## Текущий этап

```text
камера → ноутбук → локальная YOLO → HDMI-монитор
                    ↑
              полётный контроллер
```

На этом этапе проверяются:

- обнаружение объектов;
- порог уверенности;
- задержка голосового сигнала;
- вывод изображения на HDMI;
- будущие режимы `OSD` и `OBJECT`;
- получение телеметрии от полётного контроллера.

## Будущий перенос

После завершения проверки ноутбук будет заменён на Orange Pi. На Orange Pi
должен запускаться уже готовый автономный продукт: без среды разработки,
интернета и постоянного участия оператора.

```text
камера → Orange Pi → распознавание → OSD/VTX
                         ↓
                   автономный запуск
```

Ветка моделирования не меняет проверенное состояние `main`, пока результат
экспериментов отдельно не принят и не перенесён владельцем проекта.
