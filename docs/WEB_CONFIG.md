# Веб-панель VideoT16

Панель изменяет настройки локально на устройстве. Интернет для работы панели и распознавания не нужен.

## Запуск на ноутбуке или Raspberry Pi

```bash
./scripts/run_config_web.sh --host 0.0.0.0 --port 8080
```

Откройте в браузере:

```text
http://АДРЕС_УСТРОЙСТВА:8080
```

Например: `http://192.168.20.114:8080`.

## Автозапуск панели на Raspberry Pi

Это отдельная служба только для настроек. Она не заменяет и не перезапускает
автономную службу распознавания `videot16.service`.

После копирования проекта на плату установку можно выполнить готовым скриптом:

```bash
./scripts/install_config_web.sh
```

Скрипт устанавливает только `videot16-web.service`, включает его после загрузки
и выводит адрес панели. Камера, модель и служба распознавания не изменяются.

```bash
sudo install -m 0644 deploy/videot16-web.service /etc/systemd/system/videot16-web.service
sudo systemctl daemon-reload
sudo systemctl enable --now videot16-web.service
sudo systemctl status videot16-web.service
```

Отключить панель можно так:

```bash
sudo systemctl disable --now videot16-web.service
```

## Автономный Wi-Fi только для настройки перед вылетом

Wi-Fi не передаёт видео и не участвует в работе распознавания. Raspberry Pi
создаёт собственную точку доступа, телефон подключается к ней и открывает:

```text
http://192.168.50.1:8080
```

Однократная настройка точки доступа на плате:

```bash
sudo ./scripts/setup_wifi_ap.sh VideoT16 'пароль-минимум-8-символов'
```

После загрузки точка доступа работает 15 минут. В панели есть кнопка
«Завершить настройку и отключить Wi-Fi» — она отключает Wi-Fi раньше таймера.
Кнопка создаёт локальный запрос, который обрабатывает отдельная root-служба
systemd. Веб-панель сама не получает root-доступ.
Если телефон отключился, распознавание и видеопередача продолжают работать с
последними сохранёнными параметрами. При следующем включении платы окно
настройки снова доступно.

## Что можно менять

- порог уверенности обнаружения;
- размер входа нейросети и частоту инференса;
- общую подпись `OBJECT` или имена классов;
- шрифт, размер, толщину и цвет рамки объекта;
- положение и отступ подписи объекта;
- шрифт, размер, цвет, тень, положение и интервалы строк телеметрии;
- масштаб, предел, длину, толщину, цвет и тень горизонта;
- размеры, толщину, цвет и тень центральной оси;
- положение, размер, цвета, толщину и маркер шкалы газа;
- шрифт, размер, цвета, тень, нижний отступ и мигание ARM-баннера.

После нажатия «Сохранить настройки» работающий VideoT16 перечитывает файл примерно за секунду. Модель, камера и видеовыход относятся к монтажным параметрам и пока меняются в скрипте запуска.

## Файл настроек

Настройки хранятся в `config/runtime_settings.json`. Запись выполняется атомарно через временный файл, поэтому отключение питания не должно оставить наполовину записанный JSON.

Панель предназначена для доверенной локальной сети. Не открывайте порт 8080 в Интернет без отдельной аутентификации и firewall.
