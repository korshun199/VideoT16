# Foxeer F405 V2 — техническое исследование

Статус: исследование перед подключением Raspberry Pi и EasyCap.

## Идентификация

Плата имеет официальную цель `FOXEERF405V2` в Betaflight и отдельный target
`FoxeerF405v2` в ArduPilot. Не следует смешивать её с другими платами F405:
одинаковое название процессора не означает одинаковую распиновку.

## Подтверждённые узлы

- MCU: STM32F405RGT6.
- IMU: ICM42688-P.
- Барометр: DPS310.
- Аналоговый OSD: AT7456E/MAX7456.
- Flash для Blackbox: 128 Mbit, то есть 16 MB.
- Шесть UART.
- Два входа камеры: CAM1 и CA2.
- Аналоговый видеовыход: VTX.
- I2C для внешнего компаса.
- USB-C.
- До десяти PWM-выходов.
- Встроенный контроль напряжения батареи.
- Внешний вход датчика тока CUR.

## Видеотракт

Для аналоговой системы штатная логика выглядит так:

```text
CAM1 или CA2 → аналоговый OSD MAX7456 → VTX → видеопередатчик
```

`CAM1` — вход видеосигнала камеры. `CA2` — второй вход камеры. `VTX` — выход
видеосигнала на видеопередатчик. Переключение CAM1/CA2 выполняется отдельным
управляющим GPIO и зависит от прошивки.

Для EasyCap предварительная схема наблюдения:

```text
Foxeer VTX → EasyCap VIDEO
Foxeer GND → EasyCap GND
```

Так Raspberry получает видеосигнал из видеотракта полётника. Нельзя подавать
питание на видеопровод. Если EasyCap подключается параллельно штатному VTX,
нужно учитывать согласование 75 Ом; при ухудшении изображения понадобится
активный видеосплиттер или буфер.

## Распределение UART

Назначения по умолчанию для ArduPilot:

| UART | Площадки | Назначение по умолчанию |
|---|---|---|
| UART1 | RX1/T1 | телеметрия ESC |
| UART2 | R2/T2 | приёмник |
| UART3 | R3/T3 | управление VTX, Tramp |
| UART4 | R4/T4 | DisplayPort для цифрового VTX |
| UART5 | R5/T5 | GPS |
| UART6 | R6/T6 | пользовательская периферия |

Raspberry для обмена данными должна использовать свободный полный UART. Нельзя
подключать её к UART приёмника или совместно использовать UART4, если требуется
цифровой DisplayPort.

## OSD и данные распознавания

Аналоговый OSD MAX7456 рисует элементы, предусмотренные прошивкой. Обычный
UART/MSP или MAVLink передаёт данные, но не превращает автоматически координаты
рамки YOLO в произвольную графику аналогового OSD.

Для произвольных строк и координат в цифровой системе используется DisplayPort.
Для аналоговой рамки остаются два практических пути:

1. Raspberry рисует рамку на видеосигнале и отдаёт готовый композитный сигнал.
2. В прошивку полётника добавляется специальная поддержка пользовательских
   данных и элементов OSD.

Первый путь не требует изменения прошивки и лучше подходит для стендовой
проверки VideoT16.

## Питание

По заводской странице Foxeer для комплекта указано питание 4–8S, выход 5 V для
периферии и 10 V для VTX. В документации ArduPilot для платы указано 2–8S и
выходы 5 V/10 V. До уточнения конкретной ревизии следует придерживаться более
строгого варианта и не питать Raspberry от случайной площадки.

Питание Raspberry должно иметь отдельный стабильный преобразователь с запасом
по току. 5 V BEC полётника нельзя считать автоматически достаточным для
Raspberry Pi и EasyCap.

## Прошивки

- Betaflight: target `FOXEERF405V2`.
- ArduPilot: target `FoxeerF405v2`.
- Для ArduPilot аналоговый OSD использует `OSD_TYPE=1`.
- DisplayPort для цифрового VTX работает через UART4.
- Для первичной загрузки ArduPilot используется DFU и файл `with_bl.hex`, затем
  обновление выполняется через `.apj`.

Прошивку нельзя менять до сохранения текущих настроек и подтверждения точной
ревизии платы.

## Практические риски

- Перепутать `CAM1` с `VTX`.
- Подать 5 V или напряжение батареи на видеопровод.
- Перегрузить видеолинию параллельным входом EasyCap.
- Занять UART2, UART3 или UART4 не по назначению.
- Выбрать несовместимый target прошивки для похожей платы F405.
- Проверять видео только по наличию картинки и не проверить наличие OSD.

## Что ещё нужно подтвердить на конкретной плате

- Физическую маркировку `VID` и её соответствие официальному `VTX`.
- Реальное входное напряжение именно этой ревизии.
- Наличие и назначение разъёма второй камеры.
- Установленную прошивку и её текущую конфигурацию портов.
- Состояние аналогового OSD при подключении EasyCap.
