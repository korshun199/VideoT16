# Передача контекста VideoT16

Полная текущая схема, проводка, карта файлов и порядок запуска сохранены в
корневом файле [`WORKING_SCHEME.md`](WORKING_SCHEME.md). Перед продолжением
проекта сначала читать его.

Дата: 28.08.2026

## Главное правило

Проект работает как цифровой OSD-прокси. Дрон и управление им не входят в
область VideoT16. Raspberry Pi не выводит видео и не использует HDMI/J7.

## Цель

Локальная система обнаружения объектов получает видеокадр через EasyCap,
получает цифровые команды OSD от полётника, добавляет команды рамки и подписи
обнаруженного объекта и возвращает обновлённый поток цифрового OSD.

## Проверенное оборудование

- полётный контроллер: Betaflight 4.4.3;
- USB-порт контроллера: `/dev/ttyACM0`;
- MSP API: `1.45`;
- чтение телеметрии по USB работает;
- модель обнаружения: `models/military_vehicle_best.onnx`;
- EasyCap является рабочим видеовходом Raspberry Pi.
- HDMI и J7 не являются рабочими выходами.

## Оставшееся ядро проекта

- `src/detection.py` — запуск локального обнаружения;
- `src/detector.py` — ONNX-детектор;
- `src/realtime.py` — потоковая обработка кадров;
- `src/msp.py` — чтение MSP-телеметрии;
- `src/osd.py` — обмен с OSD Betaflight;
- `src/target.py` — преобразование координат цели в координаты OSD;
- `raspberry.sh` — запуск на Raspberry Pi;
- `scripts/position.py`, `scripts/move.py`, `scripts/motion.py`, `scripts/cli.py`
  — проверка положения штатного указателя;
- `scripts/startup.py` и `scripts/font.py` — работа с символами OSD;
- `models/military_vehicle_best.onnx` — локальная модель.

## Следующий этап

Заменить старый аналоговый обмен в `src/osd.py` на цифровой MSP DisplayPort:

1. Принять поток `MSP_DISPLAYPORT` от полётника.
2. Сохранить штатные команды OSD без изменения.
3. Преобразовать рамку объекта в цифровые OSD-команды.
4. Добавить подпись класса и уверенности.
5. Передать обновлённый поток дальше.
6. Проверить протокол на записи потока до подключения оборудования.

Прошивку Betaflight, штатный OSD и команды управления полётом не менять.
Сначала выполнить программный тест на виртуальных координатах, затем проверить
на подключённом контроллере без пропеллеров.
