# Передача контекста VideoT16

Дата: 28.08.2026

## Главное правило

Проект работает только со штатным OSD полётного контроллера Betaflight.
Собственное программное OSD VideoT16 не развивать и не возвращать в схему.

## Цель

Локальная система обнаружения объектов получает видеопоток с камеры,
обрабатывает его локальной моделью и передаёт координаты цели в штатный OSD
Betaflight через MSP по USB или UART. Полётный видеотракт остаётся штатным.

## Проверенное оборудование

- полётный контроллер: Betaflight 4.4.3;
- USB-порт контроллера: `/dev/ttyACM0`;
- MSP API: `1.45`;
- чтение телеметрии по USB работает;
- модель обнаружения: `models/military_vehicle_best.onnx`;
- EasyCap и Raspberry Pi использовались в предыдущих экспериментах, но сейчас
  не являются предметом работы с Betaflight OSD.

## Оставшееся ядро проекта

- `src/detection.py` — запуск локального обнаружения;
- `src/detector.py` — ONNX-детектор;
- `src/realtime.py` — потоковая обработка кадров;
- `src/msp.py` — чтение MSP-телеметрии;
- `src/osd.py` — обмен с OSD Betaflight;
- `src/target.py` — преобразование координат цели в координаты OSD;
- `raspberry.sh` — запуск на Raspberry Pi;
- `scripts/position.py`, `scripts/move.py`, `scripts/motion.py`, `scripts/cli.py`
  — проверка положения штатного указателя;
- `scripts/startup.py` и `scripts/font.py` — работа с символами OSD;
- `models/military_vehicle_best.onnx` — локальная модель.
