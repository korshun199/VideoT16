# Звуковые сигналы

Положите WAV-файл с сигналом обнаружения в этот каталог под именем:

```text
fpv_detected.wav
```

После этого `run_fpv.sh` будет воспроизводить его при обнаружении объекта. Между сигналами выдерживается пауза 3 секунды.

Поддерживается первый найденный в системе проигрыватель: `paplay`, `aplay` или `ffplay`.
