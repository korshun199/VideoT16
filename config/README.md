# Нативный редактор настроек VideoT16

`editor.py` — отдельное настольное приложение на Qt. Оно открывает настоящее
окно, не запускает браузер и не поднимает HTTP-сервер.

## Запуск на Linux

В установленном проекте редактор запускается двойным щелчком по ярлыку
`VideoT16 — настройки` на рабочем столе. Ярлык запускает
`/home/work/VideoT16/config/editor.py` через Python из `.venv` проекта.
Для окна требуется PySide6; зависимость описана отдельно в
`requirements-editor.txt`, чтобы не добавлять Qt в окружение распознавания без
необходимости.

Если Qt ещё не установлен в окружение проекта, из корня VideoT16 один раз
выполняется:

```bash
./.venv/bin/python -m pip install -r requirements-editor.txt
```

Пользователь выбирает JSON-файл и меняет поддерживаемые параметры мышью:
переключатели, ползунки, списки и палитру цветов. Поля без безопасного
элемента выбора остаются только для чтения. Изменения сохраняются в выбранный
файл каталога `config/`; копии и резервные файлы редактор не создаёт.
Перед сохранением проверяется формат JSON и контрольная сумма исходного файла,
чтобы не затереть более свежие внешние изменения. Настройки применяются при
следующем запуске системы распознавания.

Для `runtime_settings.json` кнопка «По умолчанию» подставляет значения из
`config/runtime_settings.py` (`DEFAULT_SETTINGS`), включая настольный порог
50% и частоту камеры 55 FPS. Она не записывает файл сама: для применения
значений нужно отдельно нажать «Сохранить настройки». Если сброс включит
выключенные видеовыходы J7 или OSD полётника, редактор сначала покажет
предупреждение. Дополнительные поля, которых нет в наборе программных значений,
сохраняются. Для других JSON-файлов кнопка отключена, поскольку у них нет общего
набора значений по умолчанию.

## Проверка

Тесты запускаются в проектном окружении без монитора:

```bash
QT_QPA_PLATFORM=offscreen ./.venv/bin/python -m unittest discover -s tests -p 'test_config_editor.py' -v
```

Окно настроек не встраивается в `lcam`; запуск распознавания остаётся
отдельным сценарием.
