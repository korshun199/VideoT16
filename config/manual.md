# VideoT16 — памятка по настройкам

## Настольное распознавание

Запуск из корня проекта — только:

```bash
./lcam
```

Главный файл настроек — [`settings.json`](settings.json). Меняй значения там
обычным текстовым редактором и перезапускай `./lcam`. В JSON нельзя добавлять
комментарии. Сейчас используется единственный профиль `profiles.sky`.

> Значения FPS и разрешения в файле — запрос драйверу. Реально согласованный
> камерой формат смотри в журнале запуска. Путь камеры и файл модели должны
> существовать на этом компьютере.

### `profiles.sky.settings` — камера и детектор

| Поле | Сейчас | Назначение / допустимое значение |
|---|---:|---|
| `source` | USB-видеозахват | Номер устройства строкой, например `"4"`, либо полный путь `/dev/video…`. Строка передаётся OpenCV как имя устройства; `"auto"` автоматическим выбором не является. |
| `model` | `models/anti_uav_fast_320_int8_pc.onnx` | Путь к модели относительно корня проекта либо абсолютный путь. |
| `confidence` | `0.32` (32%) | Порог для основной рамки; число больше 0 и не выше 1. |
| `min_confidence` | `0.13` (13%) | Нижняя граница кандидатов для обработки; больше 0 и не выше `confidence`. |
| `tile_size` | `640` | Размер квадратного фрагмента, пиксели; целое не меньше 32. |
| `tile_overlap` | `0.16` | Доля перекрытия соседних фрагментов: от 0 до значения меньше 0.5. |
| `full_frame` | `false` | `true` — передавать полный кадр, `false` — проверять фрагменты. |

### `profiles.sky.capture` — захват камеры

| Поле | Сейчас | Назначение / допустимое значение |
|---|---:|---|
| `pixel_format` | `YUYV` | Формат входа, обычно `YUYV` или `MJPG`; устройство должно его поддерживать. |
| `width`, `height` | `1280 × 960` | Запрашиваемые ширина и высота в пикселях; камера может не поддержать эту пару. |
| `fps` | `50` | Запрашиваемая частота кадров в секунду; фактическую смотри в журнале. |
| `buffer_size` | `1` | Буфер захвата, целое не меньше 1; малое значение помогает уменьшить задержку. |

### `profiles.sky.display` — окно

| Поле | Сейчас | Назначение / допустимое значение |
|---|---:|---|
| `window_title` | `VideoT16 — V2 YOLO` | Заголовок окна. |
| `window_width`, `window_height` | `1920 × 1200` | Желаемый размер окна в пикселях. |
| `max_frame_width`, `max_frame_height` | `1920 × 1172` | Ограничение области изображения в пикселях. |
| `scale_up` | `true` | Разрешить увеличивать изображение: `true`/`false`. |
| `fullscreen` | `true` | Полноэкранный режим: `true`/`false`. |
| `poll_delay_ms` | `1` | Пауза цикла окна в миллисекундах; обычно небольшое целое число. |

### `profiles.sky.pipeline_v2` — потоки и задержка вывода

| Поле | Сейчас | Назначение / допустимое значение |
|---|---:|---|
| `threads` | `8` | Число потоков ONNX Runtime, целое не меньше 1. |
| `submission_interval_frames` | `1` | Отправлять каждый N-й кадр на распознавание; целое от 1 до 120. |
| `display_fps` | `60` | Ограничение частоты обновления окна; целое от 1 до 120. |
| `output_delay_ms` | `2200` | Задержка показа, чтобы подставить результат к соответствующему кадру; 100–5000 мс. |
| `output_buffer_max_mb` | `512` | Максимум памяти для задержанных кадров; 64–2048 МиБ. Большие разрешение, FPS и задержка требуют больше памяти. |
| `box_hold_ms` | `1000` | Время удержания последней рамки, миллисекунды; 0–5000. |
| `max_match_distance_fraction` | `0.25` | Максимальное относительное смещение рамки при сопоставлении; больше 0 и не выше 1. |

### `profiles.sky.fast_scan` — ускоренный поиск

| Поле | Сейчас | Назначение / допустимое значение |
|---|---:|---|
| `enabled` | `true` | Включить чередование обзора и быстрого поиска рядом с найденной целью. |
| `focus_min_confidence` | `0.15` | Минимальная уверенность кандидата для фокусировки; больше 0 и не выше 1. |
| `focus_crop_width`, `focus_crop_height` | `640 × 640` | Размер области быстрого поиска в пикселях; целые не меньше 32. |
| `focus_lost_after_results` | `3` | Число результатов без подтверждения до возврата к обзору; целое не меньше 1. |

### `profiles.sky.overlay` — рамка и подпись

- `near_threshold_margin` — ширина предупредительного диапазона ниже основного
  порога (сейчас 0.1, то есть 10 процентных пунктов).
- `near_threshold_color_rgb` — цвет рамки в предупредительном диапазоне.
- `box.scale_x`, `box.scale_y` — масштаб рамки по горизонтали и вертикали.
- `box.thickness` — толщина линии в пикселях; целое не меньше 1.
- `box.color_rgb` — цвет основной рамки.
- `label.font` — встроенный шрифт OpenCV; `font_scale` — размер больше 0;
  `thickness` — толщина; `offset_y` и `min_y` задают положение подписи.
- `label.color_rgb` — цвет подписи.

Все цвета записываются как `[R, G, B]`, каждый компонент — целое от 0 до 255.

### `profiles.sky.status_panel` — строка состояния

`position` задаёт место строки; `height` — высоту в пикселях; `left` и
`text_y` — отступы; `background_color_rgb` и `text_color_rgb` — цвета;
`font`, `font_scale` и `thickness` — шрифт; `max_text_chars` ограничивает
длину строки. В строке отображаются CPU, температура, текущая уверенность и
порог.

### `profiles.sky.diagnostics` — вывод диагностики

`console_status_interval_ms` задаёт интервал диагностической строки в
миллисекундах; `0` отключает периодический вывод в консоль. Журнал создаётся
в `test_samples/video_trials/logs/`. Каталог испытаний локальный и в Git не
публикуется.

## Остальные конфигурации проекта

Эти файлы не являются дополнительными настройками настольного `./lcam`:

- `runtime_settings.json` и `runtime_settings.py` — отдельный контур
  Raspberry Pi/OSD, запускаемый через `./cam`.
- `motion_trial.json` — изолированный эксперимент компенсации движения,
  запускаемый отдельно через `./lcam3`.

Для обычной настольной работы меняй только `config/settings.json`.
