# WinT16

Windows-версия системы распознавания VideoT16. Цель — установка и запуск на Windows 10/11 x64 без отдельной установки Python или .NET.

На этапе испытаний офлайн-установщик размещает переносимый каталог с `Run.exe` и создаёт ярлык. При первом запуске программа показывает код компьютера из 12 заглавных букв/цифр. Владелец выпускает ответный код той же длины; приложение проверяет его офлайн и сохраняет `auth.dat`.

Все рабочие пути должны быть относительными к каталогу приложения. Привязка рассчитана на отсечение случайного копирования программы на другой компьютер, а не на защиту от технического анализа. Ключ модели включается в исполняемую сборку; опытный пользователь сможет извлечь его, это осознанное упрощение ради короткого телефонного кода.

Окно распознавания подстраивается под экран и масштаб DPI компьютера пользователя. Видео занимает максимально возможную ширину без искажения пропорций. В нижней панели по центру показывается отдельный файл `logo.png` с прозрачным фоном; изображение не встраивается в `Run.exe`.

Для обновления программы используется `Update.exe` и подписанный владельцем архив новой версии. Активация, настройки, модель и журналы сохраняются. Предыдущая версия остаётся в каталоге `versions`.
