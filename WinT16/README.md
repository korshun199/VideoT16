# WinT16

Windows-версия системы распознавания VideoT16. Цель — установка и запуск на Windows 10/11 x64 без отдельной установки Python или .NET.

Пользователь запускает офлайн-установщик `install.exe`, затем — `Run.exe`. При первом запуске программа проверяет `auth.dat`; если активации нет, показывает код запроса. Ответный ключ выпускается владельцем отдельно и подходит только компьютеру с соответствующим отпечатком оборудования.

Все рабочие пути должны быть относительными к каталогу приложения. Защита рассчитана на предотвращение простого копирования программы и ключа на другой компьютер.

План разработки и технические детали пока не входят в эту публичную страницу.
