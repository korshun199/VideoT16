# VideoT16

VideoT16 is a small local computer-vision playground for home experiments. It captures video from a camera, runs an object-detection model locally, and can draw simple information overlays on the video stream.

The project is intended for educational and hobby use, including playful experiments with a home cat and everyday objects. It is designed to run without a cloud AI service, so the camera stream stays on the local computer.

This repository is experimental software. It is not a safety-critical monitoring, navigation, or decision-making system.
